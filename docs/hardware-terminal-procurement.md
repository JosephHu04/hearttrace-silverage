# 老人端触控终端与安全设备采购规格（比赛原型版）

## 1. 先明确：三端不应放在同一块屏幕上

| 系统端 | 主要设备 | 是否需要采购专属硬件 |
| --- | --- | --- |
| 老人端 | 适老触控屏 / 平板一体机 | **需要**；这是本清单的核心 |
| 家属端 | 家属自己的手机、平板或电脑浏览器 | 不需要；只需响应式网页或小程序 |
| 管理端 | 管理人员电脑浏览器 | 不需要；必要时可配普通办公电脑 |
| 后端、模型、通知 | 云服务器或学校服务器 | 不安装在老人屏上 |

老人端负责“陪伴、心情打卡、量表、一键呼救、视频联络交接”；家属与管理端通过授权后的网页查看。把三端做成同屏入口会增加误操作、隐私和账号切换风险。

## 2. 推荐的比赛原型组合

### 方案 A：最适合比赛演示（推荐）

1. 一台 **13.3 英寸 Android 触控一体机 / 大屏平板**，承载老人端；
2. 一个 **有线 USB 或蓝牙实体呼救按钮**，接入老人端；
3. 一台 **普通路由器或稳定 Wi-Fi**；如场地网络不可靠，准备 4G/5G 热点作为备份；
4. 家属端与管理端使用现有手机、笔记本浏览器；
5. 防跌倒演示先使用合成事件或单独摄像头原型，**不把日常摄像头监看作为演示卖点**。

优点：采购少、可在云端调用模型、现场部署简单，也不会让防跌倒研发拖住三端 MVP。

### 方案 B：加入端侧防跌倒验证（第二阶段）

在方案 A 基础上增加一套独立边缘安全盒：

1. Jetson Orin Nano Super 8GB 开发套件或同等级边缘 AI 设备；
2. 1080p 广角 USB/UVC 或 CSI 摄像头；
3. 128GB NVMe 固态硬盘、主动散热、电源和独立设备外壳；
4. 端侧候选跌倒检测，只上传事件元数据；原始视频默认不离开设备；
5. 物理摄像头遮挡滑盖/断电开关、拍摄状态指示灯。

不要用普通云摄像头替代边缘安全盒；它会把持续监看、隐私授权和视频保存问题带入第一版。

## 3. 老人端触控屏采购规格

### 必选项

| 类别 | 比赛原型最低要求 | 建议采购目标 | 为什么重要 |
| --- | --- | --- | --- |
| 屏幕尺寸 | 10.1 英寸 | **13.3 英寸优先；床旁/墙装可选 15.6 英寸** | 10.1 英寸可用但文字和视频人物偏小；13.3 英寸更适合大字号与家人视频 |
| 屏幕面板 | IPS、1280×800 | IPS、1920×1080、雾面或低反光 | 保证可视角度、文字清晰和室内反光下的可读性 |
| 亮度 | 300 nit | 350–500 nit、可自动或手动调亮度 | 适应窗边、灯光和夜间场景 |
| 触控 | 5 点电容触控 | 10 点电容触控，支持手指和简易触控笔 | 老人主要用单指；多点不是核心，但能提高兼容性 |
| 系统 | Android 11+ | Android 13+，可配置自启动和 kiosk 模式 | 能锁定在老人端，避免误进系统设置或其他应用 |
| 内存/存储 | 4GB RAM + 64GB | **8GB RAM + 128GB eMMC/UFS** | 云端方案不需要高端 NPU；8GB/128GB 能保证视频、缓存、OTA 与长期使用 |
| 主控 | 四核 ARM | 八核 ARM（RK3588/RK3568 同级或成熟高通平台） | 重点是长期稳定播放、视频编码和浏览器性能，不是本地跑大模型 |
| 网络 | 2.4GHz Wi-Fi | 双频 Wi-Fi、千兆 RJ45、蓝牙 5.0；4G/LTE 可选 | 家庭 Wi-Fi、养老院网线与展会热点都可接入 |
| 摄像头 | 720p | 1080p / 5MP 及以上，带物理遮挡盖和硬件状态灯 | 支持视频联络，同时满足“看得见、关得掉”的隐私要求 |
| 麦克风 | 单麦 | 双麦或麦克风阵列、回声消除、降噪 | 适合坐在屏幕 0.5–2 米处讲话 |
| 扬声器 | 单 2W | 双 3W 及以上、正面出声、音量不破音 | 老人听力下降时比纸面 CPU 参数更重要 |
| 实体按键 | 电源键 | 音量 +/-、红色 SOS 键，必要时一个“返回首页”键 | 关键操作不能依赖小图标或复杂手势 |
| 安装 | 桌面支架 | 桌面支架 + VESA 75/100 壁挂孔 | 可在家中餐桌、床旁或养老机构墙面部署 |
| 电源与安全 | 常规适配器 | CCC 电源适配器、过热保护、断电后自动恢复应用 | 长期插电设备需强调稳定性与恢复能力 |

### 应要求供应商确认的能力

- 支持 Android 全托管 / kiosk 或能安装指定 kiosk launcher；老人不能随意退出应用。
- 支持开机自启、定时重启、远程 OTA、设备序列号和远程日志导出。
- 摄像头必须有物理遮挡盖或物理断电开关；状态灯不能只由软件控制。
- USB 可识别实体按钮、摄像头、麦克风；可用蓝牙作为备用，但 SOS 以有线为优先。
- 屏幕可连续工作 8 小时以上不过热、不明显降频；厂商提供保修与备件周期。
- 不预装无法卸载的广告应用；可关闭应用商店、通知栏和系统弹窗。

Android 的 lock task mode 可将全托管设备限制为允许的一个或多个应用，适合作为老人专用终端；普通“屏幕固定”不够，因为用户仍可自行退出。

## 4. 设备清单：买什么、不买什么

| 设备 | 数量 | 阶段 | 必须规格 / 采购关键词 | 备注 |
| --- | ---: | --- | --- | --- |
| Android 13.3 英寸触控一体机 | 1–2 台 | MVP | 8GB+128GB、1080p IPS、双频 Wi-Fi+RJ45、1080p 摄像头、双麦、双扬声器、VESA | 一台演示、一台备用更稳妥 |
| 桌面支架 / 壁挂臂 | 每屏 1 个 | MVP | 可调角度、防倾倒、VESA 75/100 | 台面演示优先桌面支架 |
| USB 实体 SOS 按钮 | 每屏 1 个 | MVP | 红色大按键、可配置长按 2 秒、USB HID 或明确 SDK | 不买只能触发厂商私有云的按钮 |
| 有线网线 | 2 根 | MVP | Cat5e/Cat6，3–5 米 | 展会 Wi-Fi 不稳时很关键 |
| 4G/5G 热点或带流量卡路由 | 1 台 | MVP 备用 | 双频 Wi-Fi、可供至少 5 台设备 | 仅作为网络兜底，不存敏感数据 |
| 小型 UPS | 1 台 | 建议 | 500–650VA，带浪涌保护 | 展示场景防断电；家用部署可选 |
| 蓝牙遥控/呼叫按钮 | 1 个 | 可选 | 明确支持 Android 标准 HID | 不能替代有线 SOS |
| Jetson Orin Nano Super 8GB | 1 套 | 防跌倒 P2 | 8GB、主动散热、NVMe、千兆网 | 仅做端侧视觉候选识别 |
| UVC/CSI 摄像头 | 1 个/房间 | 防跌倒 P2 | 1080p 25/30fps、90–110°、低照度表现、物理遮挡 | 与视频通话摄像头分开部署 |
| 端侧摄像头断电开关 | 1 个/相机 | 防跌倒 P2 | 物理断电、状态明显 | 比软件“关闭摄像头”可信 |
| NVMe 固态硬盘 | 1 个 | 防跌倒 P2 | 128GB 起、支持加密 | 默认不保存连续视频 |
| 家属手机 / 管理电脑 | 使用现有 | 三端联调 | 现代浏览器、稳定网络 | 不需专门采购 |

## 5. 性能边界：哪些放云端，哪些放本地

| 能力 | 放在哪里 | 触控屏需要的性能 | 说明 |
| --- | --- | --- | --- |
| 老人端页面、心情打卡、量表 | 触控屏 + 后端 | 8GB/128GB 足够 | 主要是网页/PWA 与表单交互 |
| 文字陪伴、摘要、标准量表计分 | 后端 / 云端模型 | 不需要本地 GPU | 屏幕只负责展示与音视频采集 |
| 视频联络交接 | 触控屏 | 1080p 摄像头、双麦、双扬声器、稳定网络 | 首发是“打开已绑定联络路径”，不承诺绕过微信能力 |
| SOS | 触控屏 + 服务端 | 实体按键、离线重试、网络恢复重传 | 按键应先本地提示，再写入服务端事件 |
| 跌倒候选检测 | 独立边缘安全盒 | 触控屏不承担推理 | 端侧先识别、老人确认、超时才升级 |
| 家属/管理看板 | 手机/电脑 + 后端 | 无专属屏幕要求 | 默认不展示连续视频或完整聊天 |

Raspberry Pi 5 可以作为低成本 UI 或设备网关试验板：官方规格包含 4/8/16GB 内存选项、双频 Wi-Fi、千兆网、蓝牙 5.0 和双显示输出。但它不应作为端侧跌倒 AI 的默认主机，也不应取代具备良好音视频与外壳的 Android 终端。

## 6. 防跌倒与视频隐私：必须写进采购需求

1. 摄像头只做端侧候选跌倒检测，不做日常人工实时监看。
2. 默认上传“设备在线、候选事件、老人确认结果”，不上传连续视频。
3. 事件短片段必须二次授权、加密、限时删除；比赛演示只使用合成视频。
4. 端侧设备应有明显拍摄指示灯、物理遮挡和断电开关。
5. 视觉模型误报时先用屏幕/语音询问老人是否需要帮助；无回应或确认需要帮助才升级。
6. 防跌倒模块与视频通话摄像头分开，避免把“与家人通话”误解为“被持续监控”。

NVIDIA 官方资料显示 Jetson Orin Nano Super 8GB 在 Super 模式下最高 67 TOPS、8GB LPDDR5、7–25W 功耗；选购时须同时确认散热和电源预算，不能只看 TOPS。

## 7. 现场验收清单

采购到货后用以下项目验收，而不是只看参数页：

- [ ] 开机后 30 秒内进入老人端，不出现桌面、广告或设置弹窗。
- [ ] 最大字号、高对比度和单击操作下，老人能完成“开始聊天、今日心情、一键呼救、联系家人”四个任务。
- [ ] 1 米距离正常讲话可被麦克风清晰接收；扬声器在较大音量下不明显破音。
- [ ] 摄像头遮挡关闭后，应用明确提示不可用，且实际无法采集画面。
- [ ] 按住实体 SOS 键 2 秒后，屏幕有本地反馈；断网时先本地排队，联网后能补传事件。
- [ ] 拔掉网络或切换热点后，设备在 60 秒内自动恢复服务。
- [ ] 连续播放/视频 2 小时，外壳温度、卡顿和音画同步均可接受。
- [ ] 断电恢复后，设备自动回到老人端；不会要求老人输入系统密码。
- [ ] 防跌倒演示只上传合成事件元数据，管理员不能默认看到连续视频。

## 8. 给供应商的一句话需求

> 需要一台面向老人使用的 Android 13.3 英寸触控一体机：Android 13+、8GB+128GB、1920×1080 IPS、350nit 以上、10 点触控、双频 Wi-Fi+千兆网口+蓝牙、1080p 带物理遮挡的摄像头、双麦回声消除、双 3W 以上扬声器、音量和实体 SOS 按键、USB 外设支持、VESA 75/100、开机自启、kiosk 锁定、可关闭广告与系统弹窗、CCC 电源适配器。请提供 Android 版本、主控型号、接口列表、连续运行温度、保修与远程 OTA 能力。
