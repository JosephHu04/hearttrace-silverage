# 家属端阶段审计（2026-09-11）

## 当前结论

家属端已具备可联调的 MVP 闭环：账号申请、管理端审批、账号登录、服务端授权校验、今日结构化摘要、关怀行动和审计查询。它适合比赛演示与内部试用，尚不适合承载真实老人敏感数据的公开生产环境。

本轮已修复两项 P0 问题：

1. 家属首页不再自动使用演示账号，也不会在 API 失败时回退显示模拟老人数据；未登录时不展示任何老人信息。
2. 管理员通过注册申请时必须确认对应老人；后端在同一事务中创建家属账号、老人授权关系和审计记录，因此新账号可立即读取其被授权老人的摘要。

## 后续优先级

### P0：演示前必须完成

- 接入一个短信或邮件服务，真正发送密码重置与审批通知；不得向浏览器返回重置令牌。
- 为登录、注册、重置接口增加 IP/账号限流、验证码重发限制和安全日志。
- 将家属端会话迁移为服务端签发的 HttpOnly、Secure、SameSite Cookie，并提供退出所有设备的能力。
- 注册进度查询改为“申请编号 + 已验证联系方式/验证码”，避免仅凭编号查询申请资料。

### P1：显著提升家属端体验

- 多老人切换、每位老人的独立授权范围与访问记录。
- 关怀行动历史：谁在何时联系、是否接通、后续待办和提醒。
- 视频联络改为“确认联系人—打开微信/电话入口—回填是否完成”，不读取或保存通话内容。
- 老人端确认授权与撤回授权；家属不能单独扩大查看范围。
- 事件卡增加一键呼救、跌倒候选事件的状态与联系人升级进度，默认不展示摄像头日常画面。

### P2：比赛展示加分项

- 家属周报：只展示个人基线变化、积极事件、已完成关怀，不输出疾病诊断。
- 可解释性抽屉：展示“趋势/量表/规则”来源，不展示对话全文。
- 无障碍与长辈家庭适配：大字号、语音提示、简化术语、色弱可辨状态。

## 验证记录

- 后端测试：15 项通过，覆盖审批、登录、改密、授权隔离、审计和迁移检查。
- 家属端生产构建通过。
- 人工 API 验收：家属查看今日摘要并提交视频联络；管理端检索到 `family.today_viewed` 与 `family.video_planned`；无授权读取返回 403。

## 不应做的事

- 不把“关怀指数”或模型候选信号称为抑郁、心理疾病诊断或自伤风险结论。
- 不给家属默认开放聊天全文、音视频通话内容或持续摄像头画面。
- 不将 API Key、重置令牌、JWT 或数据库文件提交到 GitHub。
