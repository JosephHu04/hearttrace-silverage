# 心迹银龄标准化筛查与对话观察边界

## 1. 产品定位

心迹银龄提供的是老年心理关怀、辅助筛查和人工跟进，不提供精神疾病诊断。对话大模型只整理候选信号，不能替老人填写量表、修改题目、计算分数、排除风险或给出医疗结论。

## 2. 比赛版本采用的标准

比赛版本以国家卫生健康行业标准 `WS/T 802-2022 中国健康老年人标准` 为统一依据：

- GDS-15：附录 B.4，按照过去一周的本人感受作答；0-8 分为“未见量表提示”，9-11 分为“需要人工关注”，12-15 分为“需要尽快人工评估”。
- GAD-7：附录 B.3，按照过去两星期的本人情况作答；0-9 分为“未见量表提示”，10-14 分为“需要人工关注”，15-21 分为“需要尽快人工评估”。

公开来源：<https://www.nhc.gov.cn/fzs/c100048/202211/ff72fed5f73c48838458fb353c99509d/files/1746697544163_41758.pdf>

量表模板版本固定为 `wst802-2022-v1`，计分规则版本固定为 `screening-wst802-2022-v1`。后续如修改题目、选项、阈值或建议文案，必须建立新版本，不能覆盖历史记录。

## 3. 对话分析与正式筛查的关系

```text
授权聊天 -> 模型提取候选情绪信号 -> 固定规则决定是否建议筛查
         -> 老人知情同意并本人作答 -> 服务端确定性计分
         -> 中高关注结果进入人工复核 -> 家属按本人分享选择查看摘要
```

对话分析可以输出积极、平稳、低落、焦虑、孤独、烦躁等观察标签，并附上结构化证据引用。它不能把聊天内容换算为 GDS-15 或 GAD-7 分数。

## 4. 数据最小化与权限

- 筛查开始前必须由老人确认本人同意。
- “分享给家属”和“分享给关怀团队”是两个独立开关，默认均为关闭。
- 老人本人可查看题目、本人答案、总分、分层和建议。
- 家属仅在有效 `daily_summary` 授权和本人主动分享后查看量表名称、完成时间、分层和关怀建议；不返回逐题答案和总分。
- 管理员与专业人员仅查看本人分享给关怀团队的结构化结果；逐题答案不进入当前管理端接口。
- 审计日志记录量表版本、分享选择和结果分层，不记录逐题答案。

## 5. 人工跟进规则

- 正常范围：仅保存本人结果，不自动创建风险事件。
- 中度关注：在本人分享给关怀团队时创建黄色人工复核事件，24 小时内复核。
- 高度关注：在本人分享给关怀团队时创建橙色人工复核事件，2 小时内优先复核。
- 量表高分本身不自动创建紧急事件。出现现实安全危险、明确自伤计划、一键呼救或确认跌倒时，进入独立紧急安全流程。

## 6. 比赛验证口径

比赛技术测试需要分别报告：

1. 对话候选信号识别的精确率、召回率、F1 与混淆矩阵；
2. 高风险安全信号的召回率和漏报案例；
3. 固定量表计分的单元测试和边界分数测试；
4. 三端权限隔离、分享撤回、人工复核和审计闭环；
5. 模型响应时间、失败重试与单次调用成本。

合成案例只能证明流程与规则没有回归，不能被表述为临床准确率。真实试用必须获得知情同意、采用脱敏数据，并由心理、医疗或护理专业人员定义金标准和复核结果。
