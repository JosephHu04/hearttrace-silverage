# AIC AI+心理健康主题赛提交执行计划

## 1. 是否需要实物

比赛没有强制要求提交量产硬件或现场交付实体设备。必须提交作品名称、作品简介、技术方案 PDF、答辩 PPT PDF 和佐证材料 PDF；3-5 分钟 MP4 演示视频与完整代码链接为建议材料。

本项目采取“可运行软件原型 + 硬件产品化规划”的参赛方式：

- 老人端、家属端、管理端与共享 API 必须能够在同一数据库上完成演示闭环；
- 老人端可使用普通电脑、平板或触控屏浏览器演示，不要求比赛前完成专用终端量产；
- 跌倒监控、嵌入式触控屏和微信视频唤起作为下一阶段扩展，技术报告中提供接口和采购规划；
- 演示和测试使用合成数据，不展示真实老人敏感信息。

## 3. 推荐答辩演示

1. 老人登录后直接进入陪伴首页；按当前知情授权设置完成一轮对话。
2. 展示会话后自动产生的结构化候选信号，并说明模型只提供待核对线索，不给出诊断。
3. 老人自愿进入 GDS-15 或 GAD-7，选择是否分享给家属和关怀团队。
4. 固定程序完成计分，中高关注结果进入管理端人工复核。
5. 管理员查看结构化证据、记录跟进决定并留下审计。
6. 家属查看本人授权的摘要，记录“已联系”或“已安排视频计划”（后者不代表已接通）。
7. 展示未授权家属访问被拒绝，以及老人一键呼救的独立安全流程。

## 4. 提交前验收

- [ ] 空数据库可迁移到最新版本，`alembic check` 无差异。
- [ ] API 自动测试、三端 lint 和生产构建全部通过。
- [ ] 演示账号、启动命令和端口写入 README。
- [ ] 建立锁定的对话分析测试集并记录数据来源。
- [ ] 计算精确率、召回率、F1、混淆矩阵、响应时间和成本。
- [ ] 至少完成一次老人、家属、管理人员三角色可用性走查。
- [ ] 技术报告、PPT和视频不出现学校名称或指导教师信息。
- [ ] 技术方案 PDF 不超过 10 MB；视频为 MP4、3-5 分钟且不超过 300 MB。
- [ ] 所有第三方模型、量表、数据、代码和素材注明来源与授权情况。

## 6. 2026-10-08 复核结论

三端页面、本地 API、全套自动测试和空库迁移已完成一轮技术验收；这证明软件原型可运行，不代表已达到临床有效性或正式交付条件。15 条合成会话的关怀分析回归中，最近一次模型输出有 1 条未通过结构校验（服务端会拒绝该输出，不会当成有效评测结果）；必须继续做稳定性测试和人工复核。尚未形成正式技术方案 PDF、答辩 PPT PDF、佐证材料 PDF，也未完成三角色真实可用性走查和效果验证，因此当前只能认定“参赛方向及原型形式符合要求”，不能认定“提交材料与应用成效已达标”。模型、量表及两款 CC0 原型形象的来源和授权应在材料中逐项列出。

## 5. 时间节点

报名与初赛作品提交截止：2026 年 10 月 15 日 20:00。截止后不能修改初赛作品。当前优先级依次为：可运行闭环、量化测试、佐证材料、技术报告、答辩 PPT、演示视频。
