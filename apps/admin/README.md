# 管理端

当前纵向切片实现风险队列、结构化证据、风险及紧急求助状态机、家属注册审核、操作时间线和审计查询，数据来自 `services/api`。

## 启动

先启动核心 API：

```bash
cd services/api
.venv/bin/uvicorn app.main:app --reload --port 8000
```

再启动管理端：

```bash
cd apps/admin
pnpm install
pnpm run dev
```

管理端默认地址为 `http://localhost:3001`。若 API 不在本机 8000 端口，通过 `NEXT_PUBLIC_API_BASE_URL` 配置。

演示界面会以 `staff-admin-001` 登录。此入口仅用于比赛开发，正式身份接入后必须关闭。

左侧“审计查询”可按动作类型、操作者、对象类型和对象 ID 组合筛选。家属端联调分支合并后，家属读取摘要和提交关怀行动的记录也会显示在同一审计台。

左侧“安全事件”用于处理老人或绑定设备发起的紧急求助。确认后家属摘要会显示正在跟进；解除、取消或重新打开必须填写说明。

左侧“注册审核”必须把申请绑定到已核验的老人账号；审核通过会同时创建最小家属授权。“关系与授权”可调整结构化摘要和关怀行动范围，也可即时撤销或重新启用授权。
