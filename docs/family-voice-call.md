# 家属—老人实时语音通话

此功能把“澳门数字动力 / 视频通话本地原型”的 LiveKit 音频传输思路接到现有家属端与老人端页面。没有复制原型中不鉴权的 `/signal`、`/events`、`/livekit-token`：通话状态由共享 API 与数据库管理，只有已登录、仍有 `care_actions` 授权的家属和对应老人可以发起、接听或领取房间凭证。通话音频不进入本项目数据库，审计只记录呼叫、接听、拒绝和结束事件。

## 本机试用

1. 在 API 环境中设置 `LIVEKIT_URL`、`LIVEKIT_API_KEY`、`LIVEKIT_API_SECRET`。本机 `livekit-server --dev` 的开发值见根目录 `.env.example`；实际配置写入被忽略的 `services/api/.env.call`。
2. 运行本地 LiveKit、共享 API、家属端（3000）和老人端（3002）。API 生产部署前执行 `alembic upgrade head`。
3. 家属端登录 `lin.demo@hearttrace.local`，老人端登录 `chen.demo@hearttrace.local`（密码见团队本地演示账号说明）；两端同时保持页面打开。家属端点击“呼叫老人”，老人端来电后点击“接听”。首次使用要允许麦克风；若浏览器拦截自动播放，点击“开启声音”。老人端也可通过首页“家人通话”气泡主动呼叫。

目前是**前台网页语音**：页面关闭或设备锁屏时不能保证接收来电；没有系统推送、视频、录音、通话回放。正式设备版还需验证真实手机与触控屏双向听音、回声抑制、弱网重连、网络跨运营商与 TURN；本机双网页/接口测试不能替代上述验收。LiveKit 开发密钥和 `ws://` 仅供本机使用，生产环境必须使用独立密钥与 `wss://`。

现行房间令牌两分钟内可用于加入指定房间。挂断后的令牌不能由本 API 撤回；正式部署前应增加媒体服务端房间关闭/踢人机制，并结合设备端前后台事件完善自动挂断。
