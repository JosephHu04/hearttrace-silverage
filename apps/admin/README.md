# 管理端

当前纵向切片实现风险队列、结构化证据、风险及紧急求助状态机、家属注册审核、个人通知中心、操作时间线和审计查询，数据来自 `services/api`。

## 启动

先启动核心 API：

```bash
cd services/api
.venv/bin/uvicorn app.main:app --reload --port 8000
```

再启动管理端：

```bash
cd apps/admin
pnpm install
pnpm run dev
```

管理端默认地址为 `http://localhost:3001`。若 API 不在本机 8000 端口，通过 `NEXT_PUBLIC_API_BASE_URL` 配置。

打开管理端后会先进入 `/account` 登录页，不再自动使用演示身份。仅在启用合成数据的本地联调环境，可用 `admin.demo@hearttrace.local` / `AdminDemo2026!` 登录；旧数据库会在启动时补齐这个账号的登录凭据。此预置账号不得用于正式环境，生产环境必须关闭演示数据并由运维安全创建真实管理员账号。忘记密码暂不支持自助找回，需线下核验。

管理工作台仅在后端管理员权限校验通过后显示。令牌过期、账号停用或主动退出时将清除当前浏览器标签页的管理会话并返回登录页。

左侧“审计查询”可按动作类型、操作者、对象类型和对象 ID 组合筛选。家属端联调分支合并后，家属读取摘要和提交关怀行动的记录也会显示在同一审计台。

左侧“安全事件”用于处理老人或绑定设备发起的紧急求助。确认后家属摘要会显示正在跟进；解除、取消或重新打开必须填写说明。

左侧“注册审核”必须把申请绑定到已核验的老人账号；审核通过会同时创建最小家属授权。“关系与授权”可调整结构化摘要和关怀行动范围，也可即时撤销或重新启用授权。

左侧“通知中心”显示当前管理账号自己的业务通知和未读数，支持仅看未读、分页、标记已读，并可从风险或安全事件通知直接定位到处置页面。通知接收人和可见范围始终由后端授权关系计算。
