# 老人端陪伴应用

老人端使用 Next.js 运行在 `3002` 端口，通过核心 API 创建隐私授权明确的会话，并使用 WebSocket 接收流式陪伴回复。时间、天气和新闻采用后端快速路由，同一份数据同时更新回复和页面卡片，不额外调用大模型。

## 本地运行

先启动 `services/api`，再执行：

```bash
cd apps/elder
npm ci
npm run dev
```

访问 `http://localhost:3002`。默认使用合成老人账号 `elder-demo-001` 进行比赛联调，可通过本地 `.env.local` 覆盖 `.env.example` 中的地址和账号。

首次进入陪伴主页时，老人需明确选择是否同意保存聊天并用于关怀分析。选择“同意并开始聊天”后，本机仅为该老人账号记住这一版本的偏好，以后登录会直接进入陪伴主页，并为每次新会话提交 `saveMessages=true`、`allowAnalysis=true`；服务端仍逐次记录会话设置和审计。未同意时不会启用保存与分析，仍可仅陪伴聊天。老人可随时在“设置”中停止后续保存与分析；已保存的内容和已发布摘要不会自动删除。正式部署需进一步补齐服务端持久授权、版本管理和跨设备撤回机制，不能把浏览器本地偏好当作完整的合规授权记录。

## 接口

- `POST /api/conversations/sessions`：老人角色创建会话并声明保存、分析授权。
- `WS /api/realtime/conversation`：第一帧发送 `authenticate`，之后发送 `message`。
- `GET /api/elder/widgets/weather`：天气卡片。
- `GET /api/elder/widgets/news`：资讯卡片。
- `GET /api/speech/health`：检查服务端语音密钥是否已配置。
- `WS /api/realtime/speech`：按住说话或连续语音对话时边录边传 PCM16，松手或一轮结束后拿最终识别文本；失败自动回退普通识别。
- `POST /api/speech/transcribe`：实时识别不可用时，把完整 WAV 转成文字并自动发送；不回填输入框或要求再次点发送。
- `POST /api/speech/synthesize`：模型出现完整短句就开始排队合成和播报，不等整段回答生成完毕。

访问令牌通过 WebSocket 第一帧传递，不放在 URL 查询参数中。

陪伴模型密钥从 `services/api/.env` 的 `DASHSCOPE_API_KEY` 读取，不放在老人端网页中。没有密钥时，页面会显示“模型未配置”并暂停发送聊天；后端断开时显示服务状态并每 5 秒尝试重连。若使用 Compose 的 `8010` 端口，需要把老人端 `NEXT_PUBLIC_API_BASE_URL` 设为 `http://127.0.0.1:8010`，并将老人端实际来源（如 `http://127.0.0.1:3002`）加入 API 的 CORS 列表。

ASR/TTS 使用另一枚服务端专用的 `SPEECH_DASHSCOPE_API_KEY`（本地放在被 Git 忽略的 `services/api/.env.speech`）。按下录音按钮或播放回复时，相应语音/文字会交由云端处理；不要将密钥写入网页环境变量。

首页按屏幕宽度呈现两种布局：电脑显示精灵、功能气泡和一个独立语音按钮；手机将唯一的“按住说话”按钮固定在底部。首页不再展示文字输入框或二次发送按钮，松手后自动识别并发送。查看对话记录后仍可使用文字输入和开启连续语音对话，作为备用入口。两种布局共用同一套会话、权限和数据逻辑，不维护两份容易产生差异的应用。

“按住说话”只在按住期间录音，松开即识别并发送；拖出按钮松开可取消，45 秒上限会强制结束。若首次弹出麦克风授权时已松手，该次录音会丢弃，不会在授权后意外发送。

“语音通话”是老人主动开启的免按键、按轮对话模式：持续收音并检测说话/停顿，约 650 毫秒静音后自动提交这一轮实时 ASR → 陪伴会话 → 分句 TTS；模型回答时暂停收音，播完后再继续。实时 ASR 经本项目后端代理并沿用老人身份验证，不直接暴露云密钥；失败时回退完整 WAV。可以随时暂停麦克风或结束，离开界面会释放录音设备。暂不支持说话中打断模型。实际手机使用须在 HTTPS 或 localhost 下授予麦克风权限。

空录音、识别为空和网络中断不会发送，页面会提示重试。语音服务离线时，页面会明确提示并保留打字聊天功能。

百炼播报返回标准 WAV，网页在播放时分析实际音量并驱动两款精灵的嘴巴开合；这属于音量同步，不是逐音素口型。语音服务每 15 秒重新检查一次，启动后无需重新打开网页。

首页角色在空闲时会随机触发招手、轻跳、探身和闪光回应，点击角色也会立即触发问候。系统思考、语音录入、回复播报、离线和紧急求助状态优先级高于待机动作，避免状态表达冲突。
